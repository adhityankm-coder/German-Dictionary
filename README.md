# German Dictionary MCP

A small remote MCP server for Claude. It provides:
- German ↔ English translation through MyMemory
- German/English dictionary lookup using English Wiktionary
- Verb reference lookup
- B1-oriented word/grammar reference retrieval for Claude to explain

## Important free-tier limits

This is a free-first hobby setup, not guaranteed unlimited service:
- Render Free web services sleep after 15 minutes without traffic and can take about a minute to wake.
- MyMemory's official anonymous translation limit is 5,000 characters/day. Supplying a valid contact email using `MYMEMORY_CONTACT_EMAIL` may raise this to 50,000 characters/day. See https://mymemory.translated.net/doc/usagelimits.php
- Wiktionary is community-maintained; coverage and grammar detail vary.
- Example sentences, synonyms, and detailed grammar explanations are generated by Claude from the retrieved reference and Claude's language knowledge, not guaranteed to be present in the API response.
- The hosted MCP URL is public unless you add an authentication layer. Do not put private data or secrets into this service.

## Deploy on Render (free)

1. Create a GitHub account if you don't already have one.
2. Create a new **public** GitHub repository named `german-dictionary-mcp`.
3. Upload `server.py`, `requirements.txt`, and `render.yaml` from this folder to the repository root.
4. Open https://render.com and sign up.
5. In Render choose **New + → Web Service**.
6. Connect GitHub and select `german-dictionary-mcp`.
7. Use these settings:
   - Runtime: Python
   - Build command: `pip install -r requirements.txt`
   - Start command: `python server.py`
   - Instance type: Free
8. Click **Deploy Web Service** and wait until Render reports **Live**.
9. Copy the service's URL, for example `https://german-dictionary-mcp-xxxx.onrender.com`.
10. Your MCP URL is that exact URL plus `/mcp`, e.g. `https://german-dictionary-mcp-xxxx.onrender.com/mcp`.

Do not copy the example URL above. Use the actual URL shown on your Render service page.

## Optional: raise MyMemory free quota

In Render, open your service → Environment → Add Environment Variable:
- Key: `MYMEMORY_CONTACT_EMAIL`
- Value: your email address

Save changes and redeploy. MyMemory states that a valid contact email can raise its daily allowance to 50,000 characters. This is subject to its terms and limits.

## Add it to Claude

1. Open Claude in a browser: https://claude.ai/customize/connectors
2. Choose **Add custom connector** (or the equivalent custom remote connector option).
3. Give it the name `German Dictionary`.
4. Paste your actual MCP URL ending in `/mcp`.
5. If Claude asks for authentication, choose the no-auth option only if offered for this server. This starter server does not implement OAuth.
6. Save, then enable the connector in a chat.

If Claude requires OAuth and does not offer a no-auth option, stop here rather than entering a password or token into an unknown field. Tell me what the screen says and we can add a proper authentication layer.

## Try these prompts in Claude

- Look up `begeistert`. Give me its English meaning, grammar pattern, synonyms and three B1 examples.
- Explain `sich beschäftigen mit + Dativ` and compare it with `sich befassen mit`.
- Translate `Ich habe mich gestern mit meinem Lehrer über die Prüfung unterhalten.` into English.
- Explain the forms of `aufstehen`: Präsens, Präteritum, Perfekt and auxiliary verb.
- Give me the German translation of “I would have gone if I had had time.”
